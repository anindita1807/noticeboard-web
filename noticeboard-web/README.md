# noticeboard-web

A one-page web app that shows school notices fetched from `noticeboard-api`.
It is the frontend half of a two-repo demo for RepoVitals Projects.

## Run

Start the API first (in the `noticeboard-api` repo: `npm install && npm start`), then:

```bash
npm install
npm run dev
```

Open the URL Vite prints (usually http://localhost:5173).

> Note: dependency versions are pinned to older releases on purpose,
> so RepoVitals has something to flag. Do not use this in production.
